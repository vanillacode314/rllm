# What's New

## v0.0.21

### ✨ What's New

- **Clickable source citations** — Chat responses now show where information comes from. Click a citation chip to read the full cited document or open the original web page.
- **Choose your web search provider** — A new "Web Search MCP" setting lets you pick which connected search service the app uses for web lookups.

### 🐛 Bug Fixes

- **More accurate document search** — Fixed a filtering bug that could return incorrect results when searching within specific documents.
